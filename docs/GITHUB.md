# Subir el proyecto a GitHub

Nombre sugerido: **inventario-equipos-san-marcos**.

Descripción sugerida: Aplicación de escritorio en C# y .NET para gestionar equipos, responsables, mantenimiento y reportes con SQL Server.

1. Crear un repositorio vacío en tu cuenta de GitHub.
2. Descomprimir el archivo de código fuente y abrir esa carpeta en GitHub Desktop.
3. Añadirla como repositorio local, revisar los archivos y crear el primer commit.
4. Publicar el repositorio en tu cuenta.

Subir solo el código, las guías, las capturas y el script SQL. El archivo `.gitignore` excluye los resultados de compilación y archivos locales. El ejecutable completo se distribuye mediante Releases, no dentro del código fuente.

El flujo de GitHub Actions compila, ejecuta las pruebas locales y genera una distribución Windows x64. Requiere que Actions esté habilitado en el repositorio.

No se ha asignado una licencia de distribución al código. Si deseas permitir su reutilización pública, elige una licencia y revisa por separado el uso del logo institucional.
